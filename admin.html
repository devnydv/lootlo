Quick Tips
  • Cards are paginated on the frontend — add sortOrder (number) to control order.
  • For category filtering, also set catSort = "mens_001" (cat + zero-padded order).
  • The Seed tab will populate sample data if your DB is empty.
  • Changes are live immediately — no redeploy needed.
Categories

Categories drive the filter chips on the home page and the category dropdown when creating cards. Set Sort Order to control chip order (lower = first).
